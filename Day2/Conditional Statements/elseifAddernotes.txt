Java if-else Statement Notes
1. Definition

The if-else statement is a decision-making statement in Java. It allows a program to execute one block of code if a condition is true,
 and another block if the condition is false.

 ==================Syntax===============================
if (condition1) {
    // Executes if condition1 is true
} else if (condition2) {
    // Executes if condition2 is true
} else if (condition3) {
    // Executes if condition3 is true
} else {
    // Executes if none of the conditions are true
}
