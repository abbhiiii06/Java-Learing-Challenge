### ✅ Day 1 - Java Basics

Today I learned the following concepts:

### 1. Data Types
Java provides different data types to store different kinds of values.

#### Primitive Data Types
| Data Type | Size | Example |
|-----------|------|---------|
| `byte` | 1 byte | 100 |
| `short` | 2 bytes | 20000 |
| `int` | 4 bytes | 123456 |
| `long` | 8 bytes | 123456789L |
| `float` | 4 bytes | 3.14f |
| `double` | 8 bytes | 3.14159265 |
| `char` | 2 bytes | 'A' |
| `boolean` | 1 bit | true / false |

---

###  2. Variables
Variables are used to store data in memory.

#### Example
```java
int age = 20;
double salary = 50000.50;
char grade = 'A';
boolean isStudent = true;
```

---

###  3. Operators
Operators perform operations on variables and values.

#### Arithmetic Operators
```java
+   Addition
-   Subtraction
*   Multiplication
/   Division
%   Modulus
```

#### Comparison Operators
```java
==
!=
>
<
>=
<=
```

#### Logical Operators
```java
&&
||
!
```

#### Assignment Operators
```java
=
+=
-=
*=
/=
```
